### <a name="_qmphm5d6rvi3"></a>**Решение**
Приведите диаграммы контекста и контейнеров в модели C4. Опишите там основные компоненты и интеграции всех элементов решения. 
- Для интеграции с системой партнерского кол-центра используется механизм передачи данных через защищенную почту
- Для интеграции с внутренней системой кол-центра используется протокол HTTPS
- Сервис bid-service по расписанию, либо при изменении ставки формирует файл  и отправляет задание отдельному сервису на отправку файл в кол центр
- Сервис bid-service является единой точкой управления ставкой и получения данныхз о ставках
- Отдельный сервис для интеграции с системами кол-центра позволяет конфигурировать и гибко добавлять адреса для передачи файлов для разных кол-центров, так же подключать другие протоколы взаимодействия при необходимости



### <a name="_bjrr7veeh80c"></a>**Альтернативы**
- С системой кол-центра в контуре банка можно было бы выстроить аналогичную интеграцию, как с партнерскими кол-центрами и подтягивать ставки через почту. 
    - Минусы: менее актуальные данные 
    - Плюсы: единый формат взаимодействия со своим и партнерскими кол-центрами

**Недостатки, ограничения, риски**
1. Ограничения: размер файла для общих условий удовлетворяет способу интеграции. При разработке требований о передаче персональных условий на каждого клиента интеграция должна быть оценена с т.з. объема данных и возможно пересмотрена
